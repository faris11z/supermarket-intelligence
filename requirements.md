# Supermarket Intelligence

## Objective

Build an ML-based system that compares Lidl, Aldi, Kaufland, Netto, REWE and EDEKA using publicly available supermarket data.

## Core Question

Given a shopping list, can we determine which supermarket provides the most suitable option based on price and customer sentiment?

## Data

The system will investigate and collect:

* Product information
* Prices
* Offers
* Store information
* Customer reviews
* Review dates

## ML / NLP

* German customer-review sentiment analysis
* Aspect-based sentiment analysis
* Price/basket analysis
* Potential price/offer prediction

## MLOps

* Data versioning
* Experiment tracking
* Model evaluation
* Automated pipelines
* Model/data monitoring
* CI/CD

## Final Output

A web/API-based application where a user enters a shopping list and receives a comparison of the six supermarkets.

## Initial Constraint

Before implementing the ML pipeline, investigate the availability, quality, licensing and update frequency of suitable public datasets.
